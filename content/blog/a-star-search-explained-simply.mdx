## What is A\* Search?

A\* is a pathfinding algorithm used in games, robotics, and AI. It finds the shortest path between two points while being smarter than just trying every possible path.

## How Does It Work?

A\* combines two key ideas:

### 1. The Cost So Far (g)

How far you've already traveled from the start point.

### 2. The Estimated Cost Ahead (h)

A guess of how far you still need to go to reach the goal.

The algorithm always explores the most promising path first: `f = g + h`

## A Simple Example

Imagine you're trying to find the shortest route through a city:

```
Start → [paths] → Goal
```

A\* will:

1. Calculate the cost of each path
2. Estimate the remaining distance
3. Always explore the most promising option
4. Stop when it reaches the goal

## Why is it Useful?

- **Games** - Finding optimal paths for NPC movement
- **Robotics** - Navigation and path planning
- **GPS** - Route optimization
- **Web Applications** - Network pathfinding

## Key Advantages

✅ Faster than Dijkstra's algorithm  
✅ Guaranteed to find the shortest path  
✅ Works with any heuristic  
✅ Widely used in industry

## When to Use It

Use A\* when you need to find the shortest path in a large space and want better performance than exhaustive search algorithms.
