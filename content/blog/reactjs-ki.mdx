## 1. ReactJS কী?

ReactJS হলো JavaScript-এর একটি library, যেটা দিয়ে আমরা সুন্দর, দ্রুত, আর reusable UI বানাতে পারি।

সহজভাবে বললে:

ReactJS হলো এমন একটা tool, যেটা দিয়ে আমরা website-এর ছোট ছোট অংশ বানিয়ে পুরো website তৈরি করি।

যেমন Mr Abul-এর দোকানের website-এ থাকতে পারে:

- Header
- Product Card
- Cart
- Button
- Footer

React-এ এগুলোকে আমরা আলাদা আলাদা Component হিসেবে বানাতে পারি।

## 2. Component কী?

একদিন Mr Abul তার দোকানের website বানাতে বসলো।

সে ভাবলো:

“আমার website-এ তো অনেক product থাকবে। প্রতিটা product-এর জন্য একই ধরনের box লাগবে। নাম, ছবি, দাম, আর একটা Buy button।”

যেমন:

চকলেট
দাম: ২০ টাকা
[Buy Now]

বিস্কুট
দাম: ১৫ টাকা
[Buy Now]

পানি
দাম: ২৫ টাকা
[Buy Now]

এখন যদি Mr Abul plain HTML দিয়ে বানায়, তাহলে তাকে বারবার একই structure লিখতে হবে।

কিন্তু React-এ সে একটা `ProductCard` component বানাতে পারে।

```jsx
function ProductCard() {
  return (
    <div>
      <h2>চকলেট</h2>
      <p>দাম: ২০ টাকা</p>
      <button>Buy Now</button>
    </div>
  );
}
```

এটাই Component।

সহজ ভাষায়:

Component মানে website-এর ছোট reusable অংশ।

যেমন বাস্তব জীবনে:

একটা ইট দিয়ে দেয়াল হয় না।
অনেক ইট মিলে দেয়াল হয়।

React-এ:

একটা Component দিয়ে পুরো website হয় না।
অনেক Component মিলে website হয়।

## 3. Props কী?

এখন Mr Abul-এর `ProductCard` component আছে।

কিন্তু সমস্যা হলো, সব product-এ যদি একই লেখা থাকে, তাহলে তো হবে না।

চকলেটের নাম চকলেট হতে হবে।
বিস্কুটের নাম বিস্কুট হতে হবে।
পানির দাম ২৫ টাকা হতে হবে।

এই জায়গায় আসে Props।

Props হলো component-এর কাছে data পাঠানোর উপায়।

```jsx
function ProductCard(props) {
  return (
    <div>
      <h2>{props.name}</h2>
      <p>দাম: {props.price} টাকা</p>
      <button>Buy Now</button>
    </div>
  );
}
```

তারপর Mr Abul ব্যবহার করতে পারে:

```jsx
<ProductCard name="চকলেট" price="২০" />
<ProductCard name="বিস্কুট" price="১৫" />
<ProductCard name="পানি" price="২৫" />
```

এখন একই component দিয়ে অনেক product দেখানো যাচ্ছে।

সহজ ভাষায়:

Props হলো component-এর কাছে বাইরে থেকে data পাঠানোর system।

বাস্তব উদাহরণ:

Mr Abul তার দোকানের কর্মচারীকে বলে:

এই product-এর নাম চকলেট, দাম ২০ টাকা।
এই product-এর নাম পানি, দাম ২৫ টাকা।

কর্মচারী একই নিয়মে product সাজায়, শুধু data বদলায়।

React-এ component একই থাকে, props বদলায়।

## 4. State কী?

একদিন একজন customer Mr Abul-এর website-এ ঢুকলো।

সে চকলেট কিনতে চায়। সে Add to Cart button চাপলো।

এখন Cart-এর number 0 থেকে 1 হওয়া উচিত।

এখানে আসে State।

State হলো এমন data, যেটা সময়ের সাথে পরিবর্তন হতে পারে।

যেমন:

- Cart count: 0
- Button click করার পর Cart count: 1
- আরেকবার click করলে Cart count: 2

React-এ state ব্যবহার করা হয় `useState` দিয়ে।

```jsx
import { useState } from "react";

function CartButton() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Cart: {count}</p>
      <button onClick={() => setCount(count + 1)}>Add to Cart</button>
    </div>
  );
}
```

সহজ ভাষায়:

State হলো component-এর নিজের memory।

Mr Abul-এর দোকানের উদাহরণে:

- কতজন customer এসেছে
- cart-এ কয়টা item আছে
- কোন product selected
- user login করেছে কি না

এগুলো state হতে পারে।

## 5. Event কী?

Mr Abul-এর website-এ একটা button আছে:

Add to Cart

কাস্টমার button চাপলে কিছু একটা happen করবে।

এই button চাপা, input লেখা, mouse move করা—এসব হলো Event।

React-এ event handle করা যায় এভাবে:

```jsx
function ButtonExample() {
  function handleClick() {
    alert("Product added to cart!");
  }

  return <button onClick={handleClick}>Add to Cart</button>;
}
```

সহজ ভাষায়:

Event মানে user কিছু করলে website তার response দেবে।

বাস্তব উদাহরণ:

কাস্টমার Mr Abul-কে বলে:

ভাই, একটা চকলেট দেন।

তখন Mr Abul চকলেট দেয়।

Website-এ user button click করলে React function চালায়।

Mr Abul প্রথমে ভাবলো:

ভালো প্রশ্ন।

React দরকার যখন website বড় হতে শুরু করে।

ধরো Mr Abul-এর website-এ আছে:

- ১০০টা product

## 7. JSX কী?

React-এ আমরা এমন code লিখি:

```jsx
function Welcome() {
  return <h1>Welcome to Abul Store</h1>;
}
```

এটা দেখতে HTML-এর মতো, কিন্তু আসলে এটা JavaScript-এর ভিতরে লেখা।

এটাকে বলে JSX।

সহজ ভাষায়:

JSX হলো JavaScript-এর ভিতরে HTML-এর মতো code লেখার system।

React JSX ব্যবহার করে কারণ এতে UI লেখা সহজ হয়।

## 9. Simple React Example: Mr Abul-এর Product List

```jsx
function ProductCard({ name, price }) {
```

## 12. Mr Abul-এর গল্প দিয়ে Final বুঝা
