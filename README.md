# Blog with Rafi

Personal developer blog built with Next.js App Router.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- MDX content files

## Features

- Homepage with featured content sections
- Blog listing powered by MDX posts
- Dynamic blog post pages
- Video Learning page with embedded YouTube videos
- About and Contact pages
- SEO sitemap and robots.txt

## Local Development

```bash
npm install
npm run dev
```

Other useful commands:

```bash
npm run build
npm run lint
npm run start
```

Open [http://localhost:3000](http://localhost:3000) in your browser during development.

## Deployment

This project is ready for Vercel deployment. The sitemap and robots metadata use the production base URL:

https://blog-with-rafi.vercel.app
